# MONO design and icon audit

Obsidian uses OLED black, graphite content surfaces and a restrained neutral radial light field. Porcelain uses white and platinum surfaces. Neither theme uses saturated app chrome. Actual media thumbnails retain source colors. Typography is SF Pro with editorial leading alignment and deliberate vertical space. Content cards are opaque; foreground paste/analyze controls use the real iOS 26 `glassEffect` inside `GlassEffectContainer`. Native navigation/tab/menu/sheet surfaces inherit system material. Reduce Transparency substitutes opaque grayscale controls; Reduce Motion disables the state spring. No stacked material imitation.

Application iconography comes from official Lucide SVGs at commit `1ef60af944de207e0d5176905a0759ba12e6ee8d`. `scripts/generate_icons.py` converts SVG geometry to native SwiftUI Path; it downloads no runtime assets. Original SVG files, source metadata and complete upstream license are in `Vendor/Lucide`. The generated shapes use a 24-unit viewbox, round caps/joins and 2-unit stroke. Standalone buttons have labels and minimum 44pt hit areas. Native UITabBar requires Image, so it receives display-scale renderings of these exact vector paths; the app does not substitute SF Symbols.

## Device visual QA checklist (not yet completed)

- Both themes on small and large iPhones; keyboard and safe-area layout.
- Accessibility text sizes, VoiceOver focus order and standalone action names.
- Icon optical alignment, stroke consistency and tab image sharpness at device scale.
- No accent colors in app-owned status/progress/destructive controls.
- Reduce Motion, Reduce Transparency, contrast and low-power behavior.
- Real empty/loading/error/paused/completed/permission-denied states.
- Share sheet extension and return-to-app inbox journey.
