# Конфиденциальность

MONO не содержит аналитики, рекламы, трекеров и обязательного разработческого сервера.

- Буфер обмена читается системным UIPasteControl только после нажатия.
- Ссылки, имена, коллекции, избранное и история задач хранятся локально в защищённой папке приложения. Ссылки могут содержать подписанные параметры доступа, необходимые для загрузки/возобновления.
- Исходный сайт/CDN получает ваш IP и сетевой запрос. Настроенный вами resolver получает только социальную ссылку и bearer-запрос; его собственная политика определяется оператором.
- Resolver token хранится в Keychain с this-device-only доступностью после первого разблокирования. Он не включается в диагностику.
- Фотографии добавляются только при вашем выборе/пресете, с контекстным add-only PhotoKit разрешением. Чтение всей фототеки не запрашивается.
- Уведомления выключены по умолчанию; разрешение запрашивается при включении.
- Share Extension обменивается небольшими URL-заявками через подписанный App Group. Не извлекает медиа и не читает другие приложения.
- Миниатюры создаются ограниченного размера, без постоянного дискового кэша. Данные скачанных файлов не меняются.
- Экспорт диагностики не содержит ссылок, имён, коллекций, токенов и адреса resolver. Только версия системы, счётчики и версии протокола.

Удаление файла из локальной библиотеки не удаляет ранее экспортированные копии из Photos/Files. Очистка истории отменённых/неуспешных задач не удаляет завершённые медиа. Удаление всех локальных файлов требует отдельного подтверждения. Настройки/пресеты можно сбросить отдельно; подключение и токен при таком сбросе сохраняются, что указано в диалоге. Для удаления токена очистите поле подключения и сохраните его.

Политика описывает реализованный исходный код; она не является результатом внешнего аудита или гарантией одобрения App Store.
